My Journey Into Web Development

Technology has always been something I've been interested in. I've always enjoyed understanding how things work, exploring new software and learning more about the technology I use every day. That interest became much more serious when I studied tech at college, where I was first properly introduced to the wider world of computing and development.

From there, I realised that I wanted to take that interest further rather than leave it as just a hobby. I began learning web development and found that I really enjoyed the process of taking an idea and gradually turning it into something that works. What started with simple pages has grown into building complete websites, experimenting with different layouts and constantly finding new problems to solve.

I'm still early in my development journey, but that's one of the things I enjoy most about it. There's always something new to learn, and each project gives me the opportunity to improve on the last. My goal is to continue developing my skills, move into more advanced areas of web development and eventually turn something I've always been interested in into a career.

My Development Journey

My progression so far in front-end development, from learning the foundations of HTML and CSS to building responsive websites and using Git for version control. Each stage represents a skill or area I've focused on as I continue working towards JavaScript and more advanced web development.

Getting Started

I started by learning the foundations of HTML and understanding how webpages are structured. This gave me the base I needed to begin building complete pages from scratch.

Learning CSS

Once I understood HTML, I moved into CSS and began learning how to control layout, spacing, colours and typography. This was where my websites started to feel like real designs rather than simple documents.

Flexbox & Grid

I began using Flexbox to create flexible layouts and later introduced CSS Grid for more complex page structures. These tools helped me understand how larger websites are organised and aligned.

Responsive Design

I started adapting my websites for tablets and mobile devices using flexible layouts and media queries. This helped me think about how a design needs to work across different screen sizes, not just desktop.

Git & GitHub

I started using Git to track changes throughout my projects instead of only saving the final result. GitHub now gives me a place to document my progress and showcase how each project develops over time..

Currently Learning: JAVASCRIPT

JavaScript is my next major step in front-end development. My goal is to use it to add real interaction and functionality to the websites I build.

Future Goal: APIs

After building a foundation in JavaScript, I want to learn how websites can work with external data and services. API-based projects will be one of the next areas I explore.

Future Goal: React

After developing a stronger understanding of JavaScript, I plan to explore React and learn how modern front-end applications are built. I want to understand components, state and how larger interactive websites can be structured efficiently.

Future Goal: Backend Development

Further into my development journey, I want to begin exploring the backend and understand what happens behind the websites I build. This will include learning about servers, databases, authentication and how front-end applications communicate with backend systems.

How I build

Project Breif

01

I start each project with a clear brief outlining the purpose of the website, its target audience, required sections and overall design direction.

Plan the Structure

02

I break the brief down into individual sections and plan the HTML structure before focusing on styling and visual details.

Build & Style

03

I build the website section by section, using HTML and CSS to turn the initial brief into a complete responsive design.

Test & Improve

04

As the website develops, I test different screen sizes, identify layout problems and refine areas that could be improved.
